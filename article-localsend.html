LocalSend：跨设备传文件，从此告别数据线和压缩画质

82K Star 的开源神器，无服务器、端到端加密，iPhone / 安卓 / Windows / Mac 全平台互传

📦 痛点：传个文件为什么这么难？

手机拍的照片想发到电脑？方案基本是这些：

  • 💾 插数据线 —— 麻烦，还经常弹窗乱跳
  • 📱 微信/QQ —— 会压缩画质、有大小限制，还污染聊天记录
  • ☁️ 网盘 —— 要上传下载，慢，隐私还悬着
  • 📤 AirDrop —— 好用，但只有苹果全家桶能用

如果你家里恰好「iPhone + Windows」或者「安卓 + Mac」混搭，那 AirDrop 直接没戏。而 LocalSend 就是来终结这个问题的。

✨ 它是什么？

LocalSend 是一个开源的跨平台文件传输工具，GitHub 上已经拿到 8.2 万 Star。核心理念一句话：像 AirDrop 一样传文件，但全平台通用、完全免费、无广告、无文件大小限制。

⚙️ 硬核在哪？聊聊它的技术原理

LocalSend 看着简单，但背后是相当讲究的设计：

1. 设备发现：广播协议

打开 App 后，设备会通过局域网 UDP 广播自己的信息（昵称、设备类型、支持的协议版本），同时监听其他设备的广播。这样不用任何中央服务器，同一 WiFi/局域网下的设备就能互相发现——这就是「没有服务器」的奥秘。

2. 传输安全：TLS 端到端加密

两台设备建立连接后，通过 HTTPS + TLS 加密传输文件。更硬核的是，LocalSend 使用自签名证书 + 证书指纹校验：接收方会在界面上看到发送方的证书指纹，双方可以比对确认，从而防止中间人攻击——哪怕在公共 WiFi 下也安全。

3. 协议开源：REST API

LocalSend 把整套协议做成了开放的 REST API 规范，任何开发者都能基于它做自己的客户端或集成——这也解释了为什么它能覆盖这么多平台。

🚀 怎么用？三分钟上手

1

下载安装：去官网 localsend.org 或各平台应用商店搜索 "LocalSend"（全平台都有）

2

连同一 WiFi：两台设备连接到同一个网络（局域网即可，无需联网）

3

发送：选择文件 → 选择目标设备 → 对方点击「接受」→ 传输完成 ✅

💡 小技巧：手机开热点给电脑连，或者两台设备连同一个路由器 WiFi，都可以互传。

⚠️ 注意事项

  • 需要在同一个局域网内（同一 WiFi / 路由器 / 热点），跨网络（异地）默认不支持
  • 部分路由器开了「AP 隔离」会导致设备互相发现不了，关掉即可
  • 虽然加密，但在公共 WiFi 传敏感文件仍建议谨慎

🎯 总结

LocalSend 完美诠释了什么叫「小而美的开源硬核」：一个协议、一套开源代码、覆盖全平台，把传文件这件小事做到极致。如果你受够了数据线和微信压缩画质，它值得成为你设备里的常驻工具。
