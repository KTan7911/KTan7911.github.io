## 四、核心界面：微信式聊天流

### 4.1 输入区
```
[🎤]  [ 说点什么…          ]  [➤]
 ↑            ↑                 ↑
左:切换键   中:文字输入框       右:发送
```
- **左侧切换键**：一键在「文字 ⌨️」和「语音 🎤」间切换
- **文字模式**：输入框 + 发送按钮
- **语音模式**：输入框变「按住 说话」按钮，发送键隐藏
- 文字模式下 Enter 发送，Shift+Enter 换行

### 4.2 语音输入（微信式）
- **按住**「按住 说话」→ 变「松开 发送」+ 顶部横幅「正在听你说… 0:03」
- **松手** → 语音气泡**直接发出**，无二次确认
- 录音 < 1 秒 → 提示说话时间太短，不记录
- 手指移出按钮范围松手 = 取消

### 4.3 消息展示
- 用户消息：右侧，珊瑚渐气泡
- 小屋/小猪消息：左侧，白气泡
- 消息上方带心情小标签，下方带 #话题 标签
- 底部小字尾巴：`14:20 · 已收好`
- 语音消息显示为 ▶ + 波形 + 时长

### 4.4 心情胶囊（输入区上方）
😤 吐槽 ｜ 😄 开心 ｜ 😌 平静 ｜ 🤔 思考 ｜ ✨ 小确幸
- 选中后变对应颜色渐变

### 4.5 铁律
- **记录发出后：不可修改、不可删除**
- 没有保存按钮，没有二次确认
- 写下去就是历史

## 五、语音处理方案

### 5.1 核心原则
> **音频先落地，转写异步跑。绝不打断情绪，不用重录。**

### 5.2 流程
```
按下录音 → 松手
   ↓
立刻保存音频（不等转写！）
   ↓
后台静默上传 + 转写（用户无感）
   ↓
转写成功 → 文字入库（前端不显示），供 AI 分析与搜索
转写失败 → 音频已安全，稍后自动重试
```

### 5.3 规则
- **原始语音保留**，前端显示语音条，可点击播放
- **转出的文字不在前端显示**（隐形字幕）
- 文字存进数据库 → 给 AI 分析、搜索用
- 断网：音频先存本地队列，联网后自动补传 + 补转
- 转写服务：高精度在线（Whisper 类），接入点在 Supabase Edge Function（二期）

## 六、两种人格

### 🫧 小屋（默认）
- 角色：情绪陪伴者
- 行为：**安静收着，不打扰**。用户单纯记录时不出声
- 用户主动说话/找它时才回应

### 🐷 小猪（二期）
- 角色：全能管家
- 能力：记账、分析问题、查询、提醒
- 唤醒：输入框 🐷 按钮（主）+ 语音说「小猪你好」（彩蛋）
- 共享同一对话流与记忆

### AI 语气
**温柔 + 清醒**：先接住情绪 → 再理清事实 → 给可执行的一小步
- 不贩卖焦虑，不说空洞鸡汤
- **永远不对用户下判决**
